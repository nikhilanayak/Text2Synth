# Checkpoints

The reproduction expects the paper's general-audio checkpoint at:

`checkpoints/630k-audioset-best.pt`

Run `ctag setup --download` to fetch it from the URL published by the CTAG
authors. The downloader validates SHA-256
`8053c9775516af2f4902e1e8281e356cc1bf7a85e8b761908170767b77c3f037`
before promoting the completed file. Checkpoints are external artifacts and
are not committed to git.
